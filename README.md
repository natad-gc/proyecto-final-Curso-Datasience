# Proyecto Final - Ciencia de Datos (Breast Cancer Wisconsin)

Autor: Nathanael Garza

En este proyecto comparo cuatro modelos de clasificación supervisada (Regresión Logística, Naive Bayes, SVM y Red Neuronal) usando el dataset de cáncer de mama de UCI para predecir si un tumor es maligno o benigno.

## Cómo correr el proyecto

1. Instalar las librerías necesarias:
en la terminal poner:
pip install -r requirements.txt

2. Ejecutar los scripts en este orden desde la carpeta principal (todos usa SEED=60 salgan los mismos resultados):

al igual que las librerias estos comando igual se ponen en la terminak 
python src/edaypreprocesamiento.py
python src/modelos.py
python src/evaluacion.py

Las tablas de resultados se guardan en reports
las graficas se guardan en reports/figures
